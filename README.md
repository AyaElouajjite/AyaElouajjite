## Projets

### Data & Machine Learning

**[FireGuard Lyon](https://github.com/AyaElouajjite/fireguard-lyon)** — Python, FastAPI, scikit-learn, MongoDB
Analyse de 2 500 incendies à Lyon et prédiction du niveau de risque par un modèle d'ensemble (Random Forest et Gradient Boosting, environ 81 % de précision). Tableau de bord interactif, API REST et rapports PDF.

### Applications web full-stack

**[Interactive Task Manager](https://github.com/AyaElouajjite/interactive-task-manager)** — React, TypeScript, Node.js, Express, MySQL
Gestionnaire de tâches avec tableau Kanban en glisser-déposer, authentification JWT, réinitialisation du mot de passe par e-mail et statistiques.

**[Parapharmacie](https://github.com/AyaElouajjite/Parapharmacie)** — C#, ASP.NET Core MVC
Application de gestion commerciale : boutique en ligne, ventes en caisse, approvisionnement fournisseurs et contrôle d'accès pour cinq rôles.

**[CatalogEcom](https://github.com/AyaElouajjite/catalogEcom)** — Python, Flask, MongoDB
Plateforme e-commerce avec catalogue à attributs variables, panier, commandes et back-office d'administration.

**[GestionPFA](https://github.com/AyaElouajjite/GestionPFA)** — Python, Django
Plateforme de suivi des Projets de Fin d'Année : binômes, sujets, rapports, échéances, messagerie et statistiques.

**[Gestion de Matériel](https://github.com/AyaElouajjite/gestionMateriel)** — Python, Django
Gestion d'un parc de matériel et suivi des emprunts et des retours.

### Application de bureau

**[Gestion de Réparations](https://github.com/AyaElouajjite/ProjetJAVA)** — Java, Swing, Hibernate, MySQL
Gestion d'un réseau de boutiques de réparation : réparateurs, clients, réparations et transactions financières, selon une architecture en couches.
